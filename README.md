## 先弄清你买的是哪种"美国住宅 IP"

住宅 IP 指 IP 注册在家庭宽带运营商名下，平台查到时看到的是普通宽带用户。原生 IP 指注册地和服务器实际所在地一致。双 ISP 是同一个 IP 带两个运营商属性标记，风控系统判断时的可信度比单 ISP 高一档。家宽 VDS 把机器托管在真实民房里，走当地家庭光纤，IP 质量最高，带宽和流量也更接近真实家庭宽带。NAT 共享版是几个人分一个 IP、只给你几个端口，便宜，但别人的违规会算到你头上。

前四个词决定平台怎么看你，最后一个决定你会不会被牵连。这几个品类的价格能差好几倍，差的是 IP 从哪来，不是 CPU 和内存。

## 住宅 IP 不等于"地区正确"

有个现成的例子值得记住。第三方对 WePC 韩国 SEJONG 节点的实测里，IP 在多数检测平台被识别为住宅网络，Netflix 和 Disney+ 韩国区解锁正常，国内平均延迟约 76ms，YouTube 4K 播放流畅。但同一份实测也写了两个问题：联通线路存在绕路；TikTok 把这条韩国 IP 识别成了新加坡。

第二个问题最要命。IP 是住宅属性、是原生韩国 IP，平台照样可能给你一个错误的地区标签，做韩国区账号就会被分到新加坡流量池。美国的节点同理，双 ISP 家宽住宅 IP 只说明 IP 的来源属性，不保证每个平台都认它。

买之前做两件事：问商家要测试 IP，用 ipinfo.io 查归属运营商是不是家庭宽带，用 scamalytics 看风险分；如果主战场是 TikTok，就用它的 IP 检测工具再看一眼识别结果。别等号养了一周才发现地区错了。
